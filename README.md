# Student Record Management System

**Course:** Systems Analysis and Design – Laboratory Exercise
**Developer:** Asuncion, Jolina T

## Description
A simple web application for adding, viewing, editing, and deleting basic student information.

## Functions
- **Create** – add a new student record
- **Read** – display all saved records in a table
- **Update** – edit an existing record
- **Delete** – remove a record (with confirmation prompt)

## Database
Supabase (PostgreSQL), table `students`: `id`, `student_id`, `full_name`, `program`, `year_level`, `email`.
See `schema.sql`.

## Technologies
HTML, CSS, JavaScript, Supabase JS client, GitHub, GitHub Pages / Vercel.

## Run locally
1. Run `schema.sql` in the Supabase SQL Editor.
2. Put your Project URL and anon key in `app.js`.
3. Open `index.html` in a browser.
